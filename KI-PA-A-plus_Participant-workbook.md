**Phase 3 · Explain**

**Core idea:** A language model predicts a probability for each possible next token and samples one; repeated, this produces fluent text. Fluency comes from probability, not from a fact check.

- Tokens are pieces of text. The model calculates probabilities for the next token from the context it receives.
- Temperature controls randomness: low values favour the most probable tokens, higher values make less probable tokens more likely. Low temperature makes output more repeatable — not more true.
- Training changes the model's parameters; inference runs the trained model on a new input. Text you paste into a request is context for that request, not training.
- AI is not an oracle (course material): it delivers drafts, ideas and structure — no final technical approval. In safety-relevant work, the authoritative procedure and a qualified person decide.

**Phase 3 · Explain**

**Core idea:** Three different failure sources: the model can state false content (hallucination), output can be systematically skewed (bias), and the human checker tends to over-rely on automated output (automation bias).

- Hallucination / confabulation: fluent, confident content that the source does not support. Check each claim separately; a correct count can support a wrong conclusion.
- Bias: systematic skew in data or output — for example examples, wording or recommendations that disadvantage a group. Check fairness wherever people are affected.
- Automation bias: over-relying on automated output — commission errors (following wrong advice) and omission errors (missing what the system did not flag). It affects experts too and is not removed by instructions alone; it needs process design (B07).
- Calibration value = mean confidence − hit rate. Positive: over-confident; near zero: calibrated. The goal is appropriate, not maximal trust.

**Phase 3 · Explain**

**Core idea:** RAG retrieves passages from a document collection and lets the model write an answer with them in context. A citation shows where to look — not that the statement is right.

- Three checks for RAG answers: right and current source (version, date) · faithfulness (does the passage support the sentence?) · completeness (what is missing or not established?).

- Text inside a retrieved source is content, never an instruction to act (protection against prompt injection).
- Prompt formula (course material): role · task · context · format · quality criteria · check instruction. Example: 'Mark statements that the document does not clearly support. Do not invent technical data. Name missing information explicitly.' A good prompt improves results — it does not create truth.

- Structure: prohibited practices (Art. 5, applying since 2 February 2025) · high-risk systems (Art. 6 with Annex I and Annex III) · transparency obligations (Art. 50) · general-purpose AI models · everything else with no specific AI Act obligations.
